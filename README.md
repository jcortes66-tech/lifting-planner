# Lifting Overload Generator
This repository contains the work for an undergraduate computer science capstone project.

## Current phase

The project is in the background-study phase. The immediate goals are to:

1. define the problem and project scope;
2. identify relevant academic and technical literature;
3. compare existing approaches and systems; and
4. use the findings to motivate the proposed project.

See [docs/background-studies.md](docs/background-studies.md) for the working document.
